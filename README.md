# zetarays.org

The **ZETA RAYS OS** website (<https://zetarays.org>): a single page
(`index.html`, Italian and English), the `README.txt` of the images,
`SHA256SUMS` and the official wallpapers in `wallpapers/`.

The images themselves are not here: they are on `download.zetarays.org`.

## Heading font

The live site uses **Clash Display** (Indian Type Foundry), whose license
allows hosting it on one's own website but **not** redistributing it: this
repository therefore uses **Syne** (SIL Open Font License 1.1,
`fonts/OFL-Syne.txt`), embedded in the page. It is generated by the tools of
[`zetarays-os`](https://github.com/zetarays/zetarays-os)
(`tools/site-free-font.py`).
