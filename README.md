# zetarays.org

Il sito di **ZETA RAYS OS** (<https://zetarays.org>): una sola pagina
(`index.html`, italiano e inglese), il `README.txt` delle immagini,
`SHA256SUMS` e gli sfondi ufficiali in `sfondi/`.

Le immagini da scaricare non stanno qui: sono su `download.zetarays.org`.

## Font dei titoli

Il sito online usa **Clash Display** (Indian Type Foundry), che la sua licenza
permette di ospitare sul proprio sito ma **non** di ridistribuire: per questo
la versione in questo repository usa **Syne** (SIL Open Font License 1.1,
`fonts/OFL-Syne.txt`), incorporato nella pagina. La generano gli strumenti di
[`zetarays-os`](https://github.com/zetarays/zetarays-os)
(`tools/sito-font-libero.py`).
